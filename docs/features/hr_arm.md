# 功能设计：机械臂子系统（hr_arm_perception / hr_arm_controller / hr_arm_driver）

- 状态：待评审
- 基准条款：技术方案 §3.12 全节、§10.3「D435i末端视觉与手眼标定 / 机械臂安全互锁 / 固定目标抓取」
- 起草：AI；签字：__________ 日期：__________

## 1. 首版任务边界（写死，不放宽）

```text
导航到已验收工作位 → 底盘停稳 → 末端 D435i 识别固定类别 → 低速抓取 → 放到固定位置 → 回零
```

**不支持**：移动中抓取、动态目标抓取、任意物体抓取、人机协作递物。
底盘存在非零运动目标时，机械臂任务一律拒绝。

## 2. 包划分与职责

| 包 | 职责 | 禁止承担 |
|---|---|---|
| `hr_arm_perception` | 末端 D435i RGB-D、目标检测、深度有效性、抓取候选、手眼变换 | 替代 Gemini 2 / S3 的导航或安全扫描 |
| `hr_arm_controller` | 抓取状态机、逆运动学、关节轨迹、工作空间与碰撞边界检查 | 硬实时 PWM、硬件急停 |
| `hr_arm_driver` | 轨迹下发、关节状态/故障读取、动作取消 | 绕过舵机控制器的限位或过流保护 |

六路舵机实时 PWM 由**独立舵机控制器**执行，不在 RK3588 上做。

## 3. 坐标系链（必须完整且唯一）

```text
base_link → arm_base_link → joint_1..joint_6 → tool0
          → d435i_link → d435i_color_optical_frame / d435i_depth_optical_frame
```

`tool0 → d435i_link` **必须**由手眼标定获得。标定文件须带机械臂序列号、D435i 序列号、
日期、软件版本和有效期；更换相机、末端、舵机零位或安装位后旧标定立即失效并拒绝抓取。

## 4. 抓取状态机

```text
IDLE → ARM_HOME → NAVIGATE_TO_WORKPOSE → BASE_STOP_CONFIRM → D435I_PRECHECK
→ DETECT_TARGET → SELECT_GRASP → PREGRASP → APPROACH → CLOSE_GRIPPER
→ LIFT_VERIFY → PLACE → RELEASE → ARM_HOME
```

| 编号 | 关键守卫条件 |
|---|---|
| ARM-1 | `BASE_STOP_CONFIRM` 要求：Nav2 目标已取消/成功 **且** `/cmd_vel_auto` 与 `/cmd_vel` 连续为零 **且** STM32 轮速为零 **且** 无人工接管。四者缺一不可。 |
| ARM-2 | `SELECT_GRASP` 同时检查：检测置信度、深度有效性、手眼变换有效期、工作空间、关节限位、夹爪开口、桌面/车体碰撞边界。 |
| ARM-3 | `LIFT_VERIFY` 以夹爪位置/电流 + 末端相机物体持续可见性等组合判定；**仅夹爪闭合不算抓取成功**。 |
| ARM-4 | 任一阶段出现取消/急停/遥控接管/安全故障/舵机故障/D435i 失效/IK 无解/碰撞预测/目标丢失/阶段超时 → 立即停止关节轨迹、撤销底盘运动许可、按冻结策略保持或张开夹爪、记录失败阶段与原始诊断。 |
| ARM-5 | 故障解除后**不得自动重试**，必须由 `hr_task_manager` 创建新任务。 |
| ARM-6 | D435i 断流、深度无效、标定失效或数据超时时，不得复用旧目标位姿。 |

## 5. 视觉训练路线

1. **目标检测**：公开 YOLO 权重出发，用本项目末端 D435i 在真实工作位采集的 RGB 微调。
   训练/验证/现场测试集按拍摄批次隔离，同场景近似帧不得跨集。
2. **平面抓取候选**：固定使用 **Cornell Grasping Dataset** 训练或初始化，输出
   `grasp_center`、`grasp_angle`、`gripper_width`、`grasp_quality`。
   Cornell 不含本机手眼外参，**必须**结合本机数据微调并做真实抓取验收。

首版策略为「检测框 + 有效深度 + 受限平面抓取」：接近方向、预抓取高度、最大开口、
下降距离和抬升高度按 `object_class` 冻结，网络只在配置允许的候选中选质量最高者。

## 6. 电气与机械边界

舵机电源必须与 RK3588、STM32 逻辑电源分支隔离，配独立保险、总使能与急停切断。
禁止舵机大电流经 RK3588、USB 线缆或 STM32 逻辑地回流。
D435i 使用独立、带应力释放的 USB 3.0 柔性线与拖链。

## 7. 算力与 USB 策略

首版 D435i **仅在机械臂任务阶段**启用工作区 RGB-D 档位，非抓取阶段关闭或降至诊断档，
避免与 Gemini 2 长期争用 USB 带宽和内存。性能超限时按 §3.12.6 降级顺序处理，
**不得**通过降低底盘安全、雷达频率、命令超时保护或绕过 Collision Monitor 解决。

## 8. 验收标准

| 编号 | 判据 |
|---|---|
| AC-1 | TF 树中 `base_link→arm_base_link→tool0→d435i_link` 完整且唯一 |
| AC-2 | 工作空间多点记录三维定位误差、时间戳同步误差、深度有效率 |
| AC-3 | 机械臂动作中请求任何底盘移动必须被拒绝 |
| AC-4 | 急停/接管/堵转/过流/越限/断流/IK 无解/超时，均在冻结时限内停止关节轨迹 |
| AC-5 | 每类目标分别保存训练/验证/现场集与真实抓取成败；不用训练图片结果代替实抓验收 |
| AC-6 | ROS graph 确认机械臂节点不发布 `/cmd_vel` |
