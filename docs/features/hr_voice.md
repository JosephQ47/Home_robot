# 功能设计：语音任务入口（hr_voice_capture / hr_voice_command）

- 状态：待评审
- 基准条款：技术方案 §3.12.2、§10.3「语音任务入口」
- 起草：AI；签字：__________ 日期：__________

## 1. 范围

语音**只产生离散任务请求**，绝不进入实时运动链。

ROS graph 检查必须确认语音节点不发布 `/cmd_vel`，也不发布任何舵机 PWM 接口。

## 2. 有限命令集（白名单，超出即拒绝）

`开始巡检`、`去<地点>`、`搜索<目标>`、`抓取<目标>`、`放到<位置>`、
`机械臂回零`、`打开/关闭夹爪`、`停止`、`回充`、`报告电量`

## 3. 接口契约

| 方向 | 名称 | 类型 |
|---|---|---|
| 发布 | `/voice/transcript` | `std_msgs/String`（审计用，含置信度） |
| 客户端 | `/task/execute` | `hr_interfaces/action/ExecuteTask`，`source=VOICE` |
| 发布 | `/voice/feedback` | `std_msgs/String`（播报内容，含拒绝原因） |

`ExecuteTask.source` 需新增 `VOICE`；任务类型需新增
`ARM_HOME`、`ARM_GRASP`、`ARM_RELEASE`、`ARM_STOP`。

## 4. 行为规则

| 编号 | 规则 |
|---|---|
| V-1 | 必须先唤醒词命中，才进入指令识别窗口。 |
| V-2 | ASR 结果必须映射到受限意图 + 白名单参数；地点/目标/放置位不在已验收配置内即拒绝。 |
| V-3 | 置信度不足、同音歧义、当前任务忙、安全前置条件不满足时，**只播报拒绝或澄清，不创建任务**。 |
| V-4 | `VOICE` 与网页任务同属普通任务，**不能抢占** HT-10A 人工接管、硬件急停、安全故障或 `SYSTEM_BATTERY` 临界回充。 |
| V-5 | 语音「停止」只能请求取消当前任务 + 机械臂安全停止；**不能**解除故障锁存，**不能**替代硬件急停。 |
| V-6 | 每条被接受和被拒绝的语音都必须落审计日志（原文、置信度、映射意图、结果、时间戳）。 |

## 5. 验收标准

| 编号 | 判据 |
|---|---|
| AC-1 | ROS graph 中语音节点无 `/cmd_vel` 或舵机接口 publisher |
| AC-2 | 白名单外命令、低置信度、非法参数均被拒绝并播报原因，且无任务创建 |
| AC-3 | 人工接管/急停/临界回充期间，语音任务全部被拒绝 |
| AC-4 | 语音「停止」不解除故障锁存（注入锁存故障后验证） |
| AC-5 | 审计日志字段完整可追溯 |
