# ROS 2 框架验收

1. 全量构建所有 `hr_*` 包。
2. 启动 `hr_bringup mock.launch.py`，确认所有进程保持运行。
3. 确认 `/task/execute` Action 和 Mock Nav2 Action 存在。
4. 提交观察任务，确认状态经过 `PRECHECK → NAVIGATING → DONE`。
5. 将 `/hr_mock_system` 的 `remote_override` 改为 `true`，确认活动任务进入 `INTERRUPTED`。
6. 将 `sensor_valid` 或 `safety_permit` 改为 `false`，确认新任务在 PRECHECK 被拒绝。
7. 检查 `/cmd_vel` 和 `/cmd_vel_auto` 没有发布者。
8. 检查 `hr_target_tracker` 在缺少真实 CameraInfo/标定参数时始终输出 `follow_allowed=false`。
9. 单独启动 `robot_bringup.launch.py` 默认参数，确认没有打开 `/dev/robot_mcu` 或 `/dev/hmmd_radar`。

Mock 测试只能证明接口与状态机连通，不能作为定位、避障、制动、目标测距或硬件安全验收。

已 source 工作区后可运行自动化基线检查：

```bash
python Home_robot/upper/tools/verify_mock_framework.py
```
